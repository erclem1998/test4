Política de Privacidad

Esta aplicación utiliza la API de Facebook únicamente para mostrar información pública de páginas. No recopilamos, almacenamos ni compartimos información personal de los usuarios.

La aplicación cumple con las políticas de privacidad de Facebook y no realiza ninguna acción automatizada fuera de los permisos otorgados explícitamente por el usuario.
